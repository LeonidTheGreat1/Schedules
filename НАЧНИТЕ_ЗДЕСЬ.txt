Добрый день!

Это готовая программа для автоматического расчёта перерывов сотрудников.
Код знать не нужно — достаточно Excel и двух нажатий мышью.

--------------------------------------------------------------------------------
БЫСТРЫЙ СТАРТ (3 шага)
--------------------------------------------------------------------------------

  1) Дважды щёлкните:  installers\1_Установить_Python.bat
     (если Python ещё не установлен — следуйте окну установщика)

  2) Дважды щёлкните:  2_Установить_программу.bat

  3) Дважды щёлкните:  3_Запустить_программу.bat

--------------------------------------------------------------------------------
ЕЖЕДНЕВНАЯ РАБОТА
--------------------------------------------------------------------------------

  • Правите файл  data\input.xlsx  (смены сотрудников)
  • Закрываете Excel
  • Запускаете  3_Запустить_программу.bat  → кнопка «Рассчитать»
  • Открываете  data\output_schedule.xlsx

--------------------------------------------------------------------------------
ДОКУМЕНТАЦИЯ
--------------------------------------------------------------------------------

  docs\ИНСТРУКЦИЯ_ДЛЯ_РУКОВОДИТЕЛЯ.md  — кратко для руководителя
  docs\ПАМЯТКА_для_сотрудников.md     — как заполнять Excel
  docs\УСТАНОВКА.md                    — подробная установка

--------------------------------------------------------------------------------
ПРОВЕРКА УСТАНОВКИ
--------------------------------------------------------------------------------

  Дважды щёлкните:  Проверить_установку.bat

--------------------------------------------------------------------------------
ПОДДЕРЖКА
--------------------------------------------------------------------------------

  При ошибке «файл занят» — закройте Excel с input/output.
  При ошибке «python не найден» — выполните шаг 1 установки Python.
